# Admin paket za Claude Code

Sadržaj:
- `ADMIN_SPECIFIKACIJA.md`: šta je admin, zašto postoji, ponašanje, definicije brojki, seed podaci.
- `PROMPT_FAZA_11.md`: prompt koji se šalje Claude Code-u (kopiraj ceo sadržaj).
- `dizajn/`: 11 frejmova (Adm1 do Adm5 desktop, PhAdm0 do PhAdm5 telefon). Svaki fajl ima svetlu temu levo i tamnu desno.

Pravilo: frejmovi su izvor istine za IZGLED, specifikacija je izvor istine za PONAŠANJE. Postojeća glavna specifikacija (PLATFORMA_SPECIFIKACIJA.md) i dalje važi za sve ostalo.
