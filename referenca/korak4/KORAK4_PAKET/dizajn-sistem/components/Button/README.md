# Button

Dugme pokreće jednu radnju. Na ekranu je samo jedno primarno dugme.

- **Primarno** (šuma): glavna radnja na svetloj pozadini, npr. Proknjiži uplatu.
- **Akcent** (limeta): glavna radnja na tamnoj pozadini.
- **Sekundarno**: izmena, nazad.
- **Tiho**: Preskoči, Kasnije.
- **Opasno**: storno, brisanje, uvek uz potvrdu.

Visina najmanje 44px. Tekst je glagol: "Pošalji fakturu", ne "OK".
